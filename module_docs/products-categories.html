🏷️ Product Categories Module

UI Actions and API Integration for Category Management

Overview

The Product Categories module manages product categorization, allowing products to be organized into hierarchical groups for better organization and filtering.

📌 Base URL: /api/products/categories

fetchCategories.ts
const fetchCategories = async () => { const token = localStorage.getItem('token'); const API_URL = import.meta.env.VITE_API_URL; const response = await fetch(`${API_URL}/api/products/categories`, { method: 'GET', headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' } }); const data = await response.json(); return data.data; };

const createCategory = async (categoryData: { name: string; parentId: number | null; description?: string; }) => { const token = localStorage.getItem('token'); const API_URL = import.meta.env.VITE_API_URL; const response = await fetch(`${API_URL}/api/products/categories`, { method: 'POST', headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' }, body: JSON.stringify(categoryData) }); if (!response.ok) { const error = await response.json(); throw new Error(error.message || 'Failed to create category'); } const data = await response.json(); return data; };

const deleteCategory = async (id: number) => { const token = localStorage.getItem('token'); const API_URL = import.meta.env.VITE_API_URL; const response = await fetch( `${API_URL}/api/products/categories/${id}`, { method: 'DELETE', headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' } } ); if (response.status === 409) { throw new Error('Cannot delete category with products assigned'); } const data = await response.json(); return data; };

Error Responses

Status Code Error Type Description
400 Bad Request Invalid category data or circular reference
401 Unauthorized Invalid or expired token
403 Forbidden Missing required permission
409 Conflict Cannot delete: has products or subcategories

Permissions

✅ Required Permissions:
  • products.categories.view - View categories
  • products.categories.create - Create categories
  • products.categories.update - Update categories
  • products.categories.delete - Delete categories

Category Hierarchy Rules

⚠️ Important:
  • Categories can have unlimited nested subcategories
  • Circular references are not allowed (a category cannot be its own parent)
  • A category with products assigned cannot be deleted
  • A category with subcategories cannot be deleted until children are removed
