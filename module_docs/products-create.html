Overview

The Add Product module handles the creation of new products in the system. It includes validation, category assignment, unit selection, and inventory initialization.

📌 Base URL: /api/products

const createProduct = async (productData: ProductForm) => { const token = localStorage.getItem('token'); const API_URL = import.meta.env.VITE_API_URL; const response = await fetch(`${API_URL}/api/products`, { method: 'POST', headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' }, body: JSON.stringify(productData) }); if (!response.ok) { const error = await response.json(); throw new Error(error.message || 'Failed to create product'); } const data = await response.json(); return data; }; // Using Axios import axios from 'axios'; const createProductAxios = async (productData: ProductForm) => { const token = localStorage.getItem('token'); const API_URL = import.meta.env.VITE_API_URL; const { data } = await axios.post( `${API_URL}/api/products`, productData, { headers: { Authorization: `Bearer ${token}` } } ); return data; };

Request Body Fields

Field Type Required Validation
name string Yes Min 2 chars, Max 255
sku string Yes Unique, alphanumeric
categoryId integer Yes Must exist
unitId integer Yes Must exist
price decimal Yes > 0
costPrice decimal No > 0
stock integer No >= 0, Default 0
description string No Max 5000 chars
images array No Array of URLs

Validation Rules

⚠️ Important:
  • SKU Uniqueness: SKU must be unique across all products
  • Price Validation: Both selling price and cost price must be greater than 0
  • Stock Validation: Initial stock cannot be negative
  • Category & Unit: Must reference valid existing IDs
  • Image URLs: Must be valid HTTP/HTTPS URLs

Error Responses

Status Code Error Type Description
400 Bad Request Validation error (duplicate SKU, invalid fields)
401 Unauthorized Invalid or expired token
403 Forbidden Missing products.create permission
422 Unprocessable Entity Invalid category or unit ID

Permissions

✅ Required Permission: products.create
