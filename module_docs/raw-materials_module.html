POST Create Raw Material

POST /api/raw-materials

Add a new raw material to the inventory. Product type is automatically set to 'raw_material'.

Request Flow

sequenceDiagram
    participant Client
    participant Router
    participant verifyToken
    participant Controller
    participant Repository
    participant Database

    Client->>Router: POST /api/raw-materials
    Router->>verifyToken: Verify JWT Token
    verifyToken->>Router: Token Valid
    Router->>Controller: createRawMaterial(req, res)
    Controller->>Controller: Set product_type = 'raw_material'
    Controller->>Repository: create(productData)
    Repository->>Database: INSERT INTO products
    Database->>Repository: Product created
    Repository->>Controller: Product object
    Controller->>Client: 201 Success Response

Field Type Required Validation
name String ✅ Yes Product name

unit_id Integer ✅ Yes Measurement unit ID

stock_quantity Integer ❌ No Current stock (default: 0)
category_id Integer ❌ No Category reference

async getAllRawMaterials(req, res) {
    try {
        const page = parseInt(req.query.page) || 1;
        const limit = parseInt(req.query.limit) || 10;
        const filters = {
            search: req.query.search,
            product_type: 'raw_material'
        };
        const offset = (page - 1) * limit;
        const result = await ProductRepository.findAll(filters, limit, offset);
        return successWithPagination(res, 'Raw materials retrieved successfully', result.rows, {
            total: result.count,
            page,
            limit
        });
    } catch (err) {
        return error(res, err.message, 500);
    }
}

Repository Logic

File: src/modules/products/products.repository.js:5-59

async findAll(filters = {}, limit = 10, offset = 0) {
    const where = {};
    if (filters.product_type) where.product_type = filters.product_type;
    if (filters.search) {
        where[Op.or] = [
            { name: { [Op.like]: `%${filters.search}%` } },
            { sku: { [Op.like]: `%${filters.search}%` } }
        ];
    }
    return await Product.findAndCountAll({
        where,
        include: [
            { model: Category, as: 'category' },
            { model: Unit, as: 'unit' }
        ],
        limit,
        offset,
        order: [['created_at', 'DESC']]
    });
}

📖 References

Product Types

Raw Material

  • product_type: 'raw_material'
  • Used in production (BOMs)
  • Purchased from suppliers
  • Has cost price

Finished Good

  • product_type: 'finished_good'
  • Manufactured from raw materials
  • Sold to customers
  • Has selling price

Purchase Order Status

  • pending - Awaiting approval
  • approved - Approved for ordering
  • received - Items received
  • cancelled - Order cancelled

Payment Methods

  • cash - Cash payment
  • bank_transfer - Bank transfer
  • cheque - Cheque payment
  • due - Credit/Due payment
