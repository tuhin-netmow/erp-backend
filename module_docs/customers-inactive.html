⭕ Inactive Customers Module

UI Actions and API Integration for Inactive Customer Management

Overview

The Inactive Customers module manages customers who have been deactivated or marked as inactive. Reactivate customers when needed.

📌 Base URL: /api/customers

UI Actions & API Integration

📋 View Inactive Customers List
UI Design API Call
🔌 API Call Code
GET /api/customers?status=inactive
fetchInactiveCustomers.ts
const fetchInactiveCustomers = async (page: number = 1) => { const token = localStorage.getItem('token'); const API_URL = import.meta.env.VITE_API_URL; const response = await fetch( `${API_URL}/api/customers?status=inactive&page=${page}`, { method: 'GET', headers: { 'Authorization': `Bearer ${token}` } } ); const data = await response.json(); return data; };
✅ Reactivate Customer
UI Design API Call
🔌 API Call Code
PATCH /api/customers/:id/status
reactivateCustomer.ts
const reactivateCustomer = async (id: number) => { const token = localStorage.getItem('token'); const API_URL = import.meta.env.VITE_API_URL; const response = await fetch( `${API_URL}/api/customers/${id}/status`, { method: 'PATCH', headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' }, body: JSON.stringify({ status: 'active' }) } ); return await response.json(); };

Permissions

✅ Required Permissions:
  • customers.view - View inactive customers
  • customers.reactivate - Reactivate customers
