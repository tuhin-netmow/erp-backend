📄 Sales Invoices Module

Generate and Manage Sales Invoices

Overview

Create, view, and manage sales invoices for completed orders. Generate PDF invoices and track invoice status.

📌 Base URL: /api/sales/invoices

API Integration

GET /api/sales/invoices
const fetchInvoices = async () => { const token = localStorage.getItem('token'); const response = await fetch(`/api/sales/invoices`, { headers: { 'Authorization': `Bearer ${token}` } }); return await response.json(); };
