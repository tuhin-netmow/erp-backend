🏖️ Leaves Module

Complete leave management system for staff leave applications, approvals, and tracking

📋 API Routes

GET /api/leaves

List all leave applications with pagination. Supports filtering by staff, status, and leave type.

Query Parameters: staff_id, status, leave_type, page, limit

POST /api/leaves

Apply for a new leave request. Staff can submit leave applications with reason and dates.

GET /api/leaves/:id

Get detailed information about a specific leave application.

PUT /api/leaves/:id

Update leave application details (dates, reason, etc.). Cannot change status directly.

PUT /api/leaves/:id/status

Approve or reject leave application. Updates status and records approver.

DELETE /api/leaves/:id

Cancel/delete a leave application (only if pending).

📊 Tables Used

  • leaves - Leave application records
  • staffs - Staff information (applicant and approver)

📋 Leave Types

The following leave types are supported:

  • annual - Annual/vacation leave
  • sick - Sick leave
  • unpaid - Unpaid leave
  • maternity - Maternity leave
  • paternity - Paternity leave
  • emergency - Emergency leave

🔄 Leave Status Flow

Pending
→
Approved or Rejected
→
Cancelled

Note: Leave applications can be cancelled by the applicant only when in "pending" status.

📝 Example API Usage

1. Apply for Leave

POST /api/leaves
{
  "staff_id": 5,
  "leave_type": "sick",
  "start_date": "2026-03-15",
  "end_date": "2026-03-16",
  "reason": "Medical appointment"
}

2. Approve Leave

PUT /api/leaves/1/status
{
  "status": "approved"
}

3. List All Leaves for a Staff

GET /api/leaves?staff_id=5&status=approved&page=1&limit=10
