✏️ Edit Sales Order Module

Complete documentation for editing pending sales orders with line-item editing capabilities

📋 Module Overview

🔄 Latest Updates (March 2026)

  • Read-Only Order Items Table - Items display as text with Edit/Delete buttons
  • Per-Item Edit Modal - Click Edit button to modify individual line items
  • Read-Only Customer Field - Customer cannot be changed on edit page
  • Enhanced Product Display - Shows Product Name, Unit, Stock, Specification
  • Real-time Calculations - Modal shows live totals as you edit
  • Specification Read-Only - Specification displays but cannot be edited in modal

📍 Module Location

Frontend Route: /dashboard/sales/orders/:id/edit

Documentation: /module-docs/sales-orders-edit

🎯 Purpose

Allow users to edit pending sales orders before confirmation. Users can modify quantities, prices, discounts, taxes, and remarks for each line item.

🔒 Status Restriction

Only pending orders can be edited. Confirmed, shipped, or completed orders cannot be modified.

✨ Key Features

  • Read-only customer display
  • Per-item edit modal
  • Real-time calculations
  • Unit & stock display
  • Product specification view

Editable Fields:

🔌 API Endpoints

GET /api/sales/orders/:id

Fetch sales order details by ID

PUT /api/sales/orders/:id

Update sales order details

POST /api/sales/orders/:orderId/items

Add New Item to Order - Add a new product to an existing order.
⚠️ Only works for pending orders
✓ Automatically deducts stock and creates stock movement

PUT /api/sales/orders/:orderId/items/:itemId

Update Single Order Item - Edit quantity, price, discount, tax, or remark for a specific item.
⚠️ Only works for pending orders
✓ Automatically adjusts stock when quantity changes

4. Save Order Changes
API Call
📱 Submit Updated Order
editOrder.tsx
import { useUpdateSalesOrderMutation } from "@/store/features/salesOrder/salesOrder";
import { toast } from "sonner";
import { useNavigate } from "react-router";

const [updateSalesOrder, { isLoading }] = useUpdateSalesOrderMutation();
const navigate = useNavigate();

const onSubmit = async (values) => {
  if (!orderId) return;
  if (values.customer_id === 0) {
    return toast.error("Please select a customer");
  }

  try {
    const payload = {
      ...values,
      items: values.items.map((i) => ({
        ...i,
        quantity: Number(i.quantity),
        unit_price: Number(i.unit_price),
        discount: Number(i.discount),
        sales_tax: Number(i.sales_tax),
      })),
    };

    const res = await updateSalesOrder({ id: orderId, data: payload }).unwrap();

    if (res.status) {
      toast.success("Sales Order Updated Successfully!");
      navigate("/dashboard/sales/orders");
    }
  } catch (error) {
    toast.error(error?.data?.message || "Failed to update sales order");
  }
};

// Form submission
<Form onSubmit={form.handleSubmit(onSubmit)}>
  {/* Form fields */}

  <Button
    type="submit"
    disabled={isUpdating}
    className="bg-blue-600 hover:bg-blue-700"
  >
    {isUpdating ? "Updating..." : "Update Sales Order"}
  </Button>
</Form>

🧮 Calculations

Line Item Calculations:

Calculations
// For each line item:
const unitPrice = Number(item.unit_price);
const quantity = Number(item.quantity);
const discount = Number(item.discount);
const taxRate = Number(item.sales_tax);

// Subtotal (before discount and tax)
const subtotal = unitPrice * quantity;

// Taxable amount (after discount)
const taxableAmount = subtotal - discount;

// Tax amount
const taxAmount = taxableAmount * (taxRate / 100);

// Line total (including tax)
const total = taxableAmount + taxAmount;

// Order totals:
const totalSubtotal = items.reduce((sum, item) => sum + item.subtotal, 0);
const totalDiscount = items.reduce((sum, item) => sum + item.discount, 0);
const totalTax = items.reduce((sum, item) => sum + item.taxAmount, 0);
const grandTotal = items.reduce((sum, item) => sum + item.total, 0);

⚠️ Error Handling

Error Cause Solution
Order not found Invalid order ID Verify order ID exists
Order not pending Order status is not "pending" Only pending orders can be edited
Invalid customer Customer ID doesn't exist Select valid customer
Invalid product Product ID doesn't exist Select valid products
Quantity too low Quantity < 1 Set minimum quantity of 1
Invalid dates Due date before order date Set due date after order date
