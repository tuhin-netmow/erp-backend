🖥️ POS Order Module

Point of Sale Interface for Quick Order Processing

Overview

The POS (Point of Sale) module provides a fast, intuitive interface for processing sales orders in retail environments. Designed for quick checkout and real-time inventory management.

📌 Base URL: /api/sales

🔌 API Call Code
POST /api/sales/pos
createPOSOrder.ts
const createPOSOrder = async (orderData: { items: CartItem[]; customerId: number; paymentMethod: string; }) => { const token = localStorage.getItem('token'); const API_URL = import.meta.env.VITE_API_URL; const response = await fetch(`${API_URL}/api/sales/pos`, { method: 'POST', headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' }, body: JSON.stringify(orderData) }); if (!response.ok) { throw new Error('Failed to create POS order'); } return await response.json(); };
