👥 Products for Staff Module

UI Actions and API Integration for Staff Product View

Overview

The Products for Staff module provides staff members with access to view and manage products. This module has restricted permissions - sensitive data like cost price and profit margins are hidden from staff view.

📌 Base URL: /api/products/staff
⚠️ Staff Restrictions: Staff members have read-only access to products. Sensitive fields like cost price, supplier information, and profit margins are not included in staff responses.

🔌 API Call Code
GET /api/products/staff/products
fetchStaffProducts.ts
const fetchStaffProducts = async ( page: number = 1, search?: string ) => { const token = localStorage.getItem('token'); const API_URL = import.meta.env.VITE_API_URL; const params = new URLSearchParams({ page: page.toString(), limit: '20' }); if (search) { params.append('search', search); } const response = await fetch( `${API_URL}/api/products/staff/products?${params}`, { method: 'GET', headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' } } ); if (!response.ok) { throw new Error('Failed to fetch products'); } const data = await response.json(); return data; }; // Using Axios import axios from 'axios'; const fetchStaffProductsAxios = async ( page: number = 1, search?: string ) => { const token = localStorage.getItem('token'); const API_URL = import.meta.env.VITE_API_URL; const { data } = await axios.get( `${API_URL}/api/products/staff/products', { params: { page: page, limit: 20, search }, headers: { Authorization: `Bearer ${token}` } } ); return data; };

🔌 API Call Code
GET /api/products/staff/:id
fetchStaffProductDetails.ts
const fetchStaffProductDetails = async (id: string) => { const token = localStorage.getItem('token'); const API_URL = import.meta.env.VITE_API_URL; const response = await fetch( `${API_URL}/api/products/staff/${id}`, { method: 'GET', headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' } } ); if (response.status === 404) { throw new Error('Product not found'); } if (response.status === 403) { throw new Error('Access denied: Insufficient permissions'); } const data = await response.json(); return data.data; };

Error Responses

Status Code Error Type Description
401 Unauthorized Invalid or expired token
403 Forbidden Missing products.staff.view permission
404 Not Found Product does not exist or is not accessible to staff

Permissions

✅ Required Permissions:
  • products.staff.view - View products in staff mode

Staff members automatically have filtering applied to hide sensitive fields:

  • ❌ Cost price
  • ❌ Supplier information
  • ❌ Profit margins
  • ✅ Product name, SKU, selling price
  • ✅ Stock levels
  • ✅ Category information
