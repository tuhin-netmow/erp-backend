⏳ Pending Sales Orders Module

View and Manage Pending Sales Orders

Overview

View and manage all pending sales orders that await confirmation. Process pending orders and convert them to confirmed status. This module provides comprehensive tools for managing orders that haven't been confirmed yet.

📌 Base URL: /api/sales/orders

Status Flow

📊 Pending Order Status Options:
  • pending - Initial state, awaiting confirmation
  • confirmed - Order confirmed by sales team
  • cancelled - Order cancelled (with reason)
  • failed - Order processing failed

Permissions

✅ Required Permissions:
  • sales.orders.view - View pending orders
  • sales.orders.edit - Edit and confirm orders
  • sales.orders.delete - Delete orders
  • sales.delivery.update - Update order status

Best Practices

⚠️ Important Notes:
  • Always confirm order details before changing status from pending
  • Pending orders can only be edited when status is "pending"
  • Once confirmed, orders cannot be deleted, only cancelled
  • Provide cancellation reasons when cancelling pending orders
  • Use bulk actions carefully - affects all selected orders
